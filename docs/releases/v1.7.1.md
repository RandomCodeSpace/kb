# kb v1.7.1

v1.7.1 lowers kb's minimum Go version from 1.26.6 to 1.26.5. A machine
running Go 1.26.5 can now install kb with `GOTOOLCHAIN=local`, which prevents
Go from downloading a newer toolchain.

This release does not change kb commands, features, dependencies, the database
schema, or local-only storage. GitHub Actions also uses `GOTOOLCHAIN=local` so
CI and release builds fail instead of silently selecting a newer Go version.

## Upgrade

With Go 1.26.5 or newer:

```sh
GOTOOLCHAIN=local go install github.com/RandomCodeSpace/kb@v1.7.1
kb version
```

The release provides CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Each binary records Go 1.26.5 in its embedded
build metadata.
