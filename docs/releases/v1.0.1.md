# kb v1.0.1

v1.0.1 is a terminal-workflow patch release. It improves pointer interaction,
rendering stability, and detail-pane containment without changing the command
surface or database format introduced in v1.0.0.

## Terminal workflow

- Pointer interaction is now the primary route for visible board and overlay
  actions. Cards can be opened and dragged; forms, checklist and lifecycle
  choices, comments and links, Settings, ADR review, and forge Import controls
  use the same state machines as their keyboard equivalents.
- Card editors expose visible Save and Cancel controls. `Ctrl+Enter` provides a
  save fallback when terminal flow control consumes `Ctrl+S`.
- The mouse wheel scrolls hovered board columns and card detail. An outside
  left-click closes an idle detail pane without dismissing destructive
  confirmations.
- Detail panes clamp their frame, content, and scroll position to the active
  terminal viewport across full-screen scrolling and resize.
- Keyboard help is available from the board, and uppercase `X` clears filters
  without conflicting with lowercase `x` card cancellation.
- Watcher refreshes retain the ready footer after the initial board load, and
  rendering takes its clock value from model state for deterministic frames.

## Quality

- Golden terminal tests now compare final cell grids instead of renderer-order
  escape bytes.
- The Quality workflow again includes the Go SonarQube Cloud analysis.
- Pointer and terminal tests cover press/release routing, drag moves, keyboard
  save paths, and viewport boundary behavior.

## Upgrade from v1.0.0

No database migration is required. Existing tasks, comments, links,
tombstones, settings, encrypted credentials, and import provenance remain in
the same data directory. Keep `kb.db`, `kb.db-wal`, `kb.db-shm`, and `secret`
together when backing up or moving a board.

## Install and verify

With Go 1.25.8 or newer:

```sh
go install github.com/RandomCodeSpace/kb@v1.0.1
kb version
```

The release contains five CGO-free binaries:

- Linux amd64 and arm64
- macOS amd64 and arm64
- Windows amd64

Download the matching binary and `SHA256SUMS` from the release, then verify it
before installation:

```sh
grep ' kb-linux-amd64$' SHA256SUMS | sha256sum -c -
```

Substitute the downloaded asset name. On macOS, pipe the matching manifest
line to `shasum -a 256 -c -`. On Windows, compare
`Get-FileHash -Algorithm SHA256` with the matching manifest line.

Every attached binary is built from the annotated v1.0.1 tag with `-trimpath`
and stripped debug data. Embedded Go metadata records the module, version,
source revision, target OS and architecture, and an unmodified source tree.
