# kb v1.0.0

kb is now terminal-first. The full local workflow lives in the TUI, task CLI,
and MCP server, all backed directly by the same SQLite database. The optional
HTTP server remains for remote clients and integrations; the browser UI and its
JavaScript toolchain are gone.

## Breaking command change

- Bare `kb` opens the TUI when stdin and stdout are terminals.
- Bare `kb` prints root help when either stream is redirected.
- The API server now starts explicitly with `kb serve`.
- Former root server flags such as `kb --port 8080` fail with migration
  guidance; use `kb serve --port 8080`.
- The HTTP root and static-asset paths no longer exist. `/api/*` remains.

This command-surface break is why the release is v1.0.0 rather than another
v0.x release.

## Terminal workflow

- Responsive Miller-column board with keyboard and mouse navigation.
- Card detail, create/edit, filters, comments, blocker links, and checklist
  management.
- Transactional moves, guarded shipping and auto-shipping, cancellation,
  restore, and Cancelled-only permanent deletion.
- AI-assisted card drafting and ADR splitting with manual review before writes.
- Forge issue import, duplicate detection, provenance, and read-only drift
  review.
- Store-backed settings for AI providers, forge sources, identity, and display
  preferences.

The shared AI runner now serves the TUI and the API without making the local UI
depend on an HTTP process. The task CLI and MCP server remain local by default.

## Upgrade from v0.14.2

No database migration step is required. Stop every old writer, back up
`kb.db`, `kb.db-wal`, `kb.db-shm`, and `secret` together, then point v1.0.0 at
the same data directory. Existing tasks, comments, links, tombstones, settings,
encrypted credentials, and import provenance are retained.

Before replacing an API deployment, change its command or service unit from
bare `kb` to `kb serve`. A reverse proxy may continue forwarding `/api/*`, but
there is no HTML application at `/`.

See the README upgrade section for Entra and token-mode board identity details.

## Install and verify

With Go 1.25.8 or newer:

```sh
go install github.com/RandomCodeSpace/kb@v1.0.0
kb version
```

The release also contains five CGO-free binaries:

- Linux amd64 and arm64
- macOS amd64 and arm64
- Windows amd64

Download the matching binary and `SHA256SUMS` from the release, then verify it
before installation:

```sh
grep ' kb-linux-amd64$' SHA256SUMS | sha256sum -c -
```

Substitute the downloaded asset name. On macOS, pipe the matching manifest
line to `shasum -a 256 -c -`. On Windows, compare
`Get-FileHash -Algorithm SHA256` with the matching manifest line.

Every attached binary is built from the annotated v1.0.0 tag with `-trimpath`
and stripped debug data. Embedded Go metadata records the module, version,
source revision, target OS and architecture, and an unmodified source tree.
