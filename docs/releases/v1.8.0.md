# kb v1.8.0

v1.8.0 adds `kb web`, a browser view of the same local board with every TUI
capability and a more polished design. The database schema, the CLI verbs, and
the MCP tools are unchanged; nothing listens on a port unless you run `kb web`.

## Web UI

- `kb web` starts a loopback HTTP server, prints its URL, and opens the
  browser. `--addr` fixes the port, `--no-open` prints the URL only, and
  `--data` selects the data directory. A non-loopback address is refused
  unless `--unsafe-listen` is given; the web UI has no authentication.
- The board shows the four columns with drag and drop, keyboard navigation
  matching the TUI, a command palette on `Ctrl+K` built from the TUI action
  registry, inline quick-add with `!prio`, `#label`, `@date`, and `~effort`
  tokens, quick filters, search tokens such as `tag:`, `prio:`, `due:`,
  `is:blocked`, and `scope:`, multi-select bulk actions, per-column WIP
  limits, collapsible columns, and undo for moves and cancellations.
- Markdown renders everywhere text appears: card bodies and titles, the
  detail panel, comments, and the editor preview. The description and comment
  editor has a toolbar, `Ctrl+B`, `Ctrl+I`, `Ctrl+K`, and `Ctrl+E` shortcuts,
  list continuation, and a live side-by-side preview.
- Scoped labels (`scope::value`) render as two-tone chips with one color per
  scope, hold one value per scope in every editor, and group by scope in the
  label picker and the filter row.
- Settings mirror the TUI pane: the AI base URL, model, and API key with a
  connection test, and GitLab or GitHub forge sources with stored tokens and a
  probe.
- AI drafting fills the card editor for review before saving, the ADR split
  proposes stories for review before creation, and the forge import wizard
  previews issues with duplicate markers before importing them with
  provenance and a drift baseline. Drift checks and baseline updates live in
  the detail panel next to the card's provenance.
- Cancelling asks for an optional reason and cancelled cards show their
  tombstone. Shipping with open checklist items offers to tick everything or
  ship anyway, and the header counts what shipped today.
- Light and dark themes derive from the TUI palette; the layout adapts from
  four columns down to a single-column phone view with full-screen sheets.

## Local HTTP API

- The web UI talks to a JSON API under `/api/` on the same loopback listener,
  documented in `docs/web-api.md` and the feature files beside it. Mutating
  requests must be same-origin with a JSON content type; request bodies are
  capped at 1 MiB; no CORS headers are emitted.

## Build

- The web stylesheet is compiled ahead of time with the standalone Tailwind
  CLI and committed, so `go build` and `go install` need no JavaScript
  toolchain. `scripts/build-web-css.sh` regenerates it and `--check` verifies
  the committed output.
- Fonts load from Google Fonts when the browser is online and fall back to the
  system stack otherwise. The markdown renderer and sanitizer are vendored
  under `internal/webui/static` with their licenses listed in `VENDOR.md`.

## Upgrade

Make a cold backup of the data directory first. Then, with Go 1.26.5 or newer:

```sh
GOTOOLCHAIN=local go install github.com/RandomCodeSpace/kb@v1.8.0
kb version
kb web
```

The release provides CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Each binary records Go 1.26.5 in its embedded
build metadata.
