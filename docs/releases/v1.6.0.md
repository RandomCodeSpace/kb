# kb v1.6.0

v1.6.0 replaces kb's previous agent runtime with Plasmid v0.1.3. The capability
probe, tool-free completions, skill runs, and exact board tools now use the
Plasmid one-shot runtime. kb owns its skill catalog and adapts its tools
directly to Google ADK interfaces instead of routing them through a compatibility
facade.

The migration keeps the existing AI contracts. Chat Completions remains the
provider protocol. Tool scopes stay exact, calls run sequentially in response
order, and the existing model-call and per-response tool-call limits still
apply. Partial cards survive only the documented budget exits. Call IDs are
normalized, tool results keep their expected wire shape, and leaked reasoning
is removed from final text.

Local probe and run failures now retain safe, actionable categories for bad
credentials, provider status, DNS, TLS, timeout, redirect policy, oversized
responses, and invalid responses. The optional HTTP server continues to redact
upstream 502 details, so remote callers do not gain a reachability oracle.

The previous runtime is absent from the source and selected module graph.
Plasmid is the sole AI agent runtime, and `openai-go` resolves to Plasmid's
tested v3.49.0 dependency. There is no runtime flag, fallback engine,
compatibility package, database migration, or change to the CLI, HTTP API, MCP
tool surface, JSON wire, or stored AI settings.

## Install and verify

With Go 1.26.6 or newer:

```sh
go install github.com/RandomCodeSpace/kb@v1.6.0
kb version
```

The release contains CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Download the matching binary and `SHA256SUMS`
from the release, then verify it before installation. For Linux amd64:

```sh
grep ' kb-linux-amd64$' SHA256SUMS | sha256sum -c -
```

Each binary records the module version, source revision, target platform, Go
1.26.6 toolchain, and an unmodified source tree in its embedded build metadata.
