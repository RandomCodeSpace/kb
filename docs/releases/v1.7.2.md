# kb v1.7.2

v1.7.2 is the first release under the MIT license and closes the gaps found by
the local-only readiness audit. It does not change kb commands, features,
dependencies, the database schema, or local-only storage.

## Fixes

- Local writes now wait up to the configured five seconds for another kb
  process holding the write lock. Before this release a write that raced a
  second process could fail after roughly 55 milliseconds.
- Starting kb in a directory that holds `kb.db-wal` or `kb.db-shm` without
  `kb.db` now refuses to create a new secret and asks for a whole-directory
  restore.
- The TUI keeps saving display preferences when a data directory contains
  more than one legacy preference file. It uses defaults, shows one notice,
  and writes the stable `.kb-tui/preferences.json` on the next save.
- The card detail drift view explains that a legacy import had no original
  snapshot and that comparison starts with the first check.
- `kb version` and `kb tui` report usage errors with exit code 2 and print
  help for `-h`, matching `kb mcp`.
- The global help describes `--json` accurately.
- Windows no longer fails secret creation on the directory sync call.

## Documentation

- The README backup section states the full restore procedure and the
  unsupported cases: live copies, database-only copies, overlaid restores,
  network filesystems, synced folders, multi-host use, and downgrades.
- The repository carries an MIT `LICENSE`.

## Known limitation

kb builds with Go 1.26.5 so that a local Go 1.26.5 toolchain installs it
without downloading a newer Go. Five Go standard library advisories fixed in
Go 1.26.6 remain reachable through the optional outbound AI and forge
integrations. This is tracked as an accepted risk in issue #297.

## Upgrade

Make a cold backup of the data directory first. Then, with Go 1.26.5 or newer:

```sh
GOTOOLCHAIN=local go install github.com/RandomCodeSpace/kb@v1.7.2
kb version
```

The release provides CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Each binary records Go 1.26.5 in its embedded
build metadata.
