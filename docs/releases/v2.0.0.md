# kb v2.0.0

kb is now a local-only kanban tool. The TUI, task CLI, and MCP server all open
the same SQLite database directly. There is no hosted account, browser UI,
remote board mode, sync service, or inbound network listener.

This is a major release because it removes `kb serve`, the HTTP API, hosted
authentication, remote CLI selection, and the `KB_SERVER` and
`KB_SERVER_TOKEN` configuration. Scripts and clients that used those features
must move to the local CLI or MCP over stdio. Historical database rows are not
deleted during the upgrade.

AI-assisted drafting and GitHub or GitLab imports remain available. They make
user-initiated outbound requests while board storage stays local. Private AI
endpoints are allowed by default so a local Ollama daemon works without an
extra launch variable. Set `KB_AI_ALLOW_PRIVATE=0` to restore the private
address block.

The local product includes the full task lifecycle, projects, comments,
blocker links, stable task numbers, JSON output, 12 MCP tools, AI review flows,
forge provenance, schema migration, and cold-copy recovery. The new README
documents installation, daily use, backup, restore, AI setup, and MCP setup.

This release contains the local-only change merged in
[#277](https://github.com/RandomCodeSpace/kb/pull/277) and the private AI
endpoint default in [#285](https://github.com/RandomCodeSpace/kb/pull/285).

## Upgrade

Back up the complete kb data directory before first launch. Copy `kb.db`, its
SQLite sidecars, the generated `secret`, preferences, and custom skills as one
unit while no kb process is writing. If `KB_SECRET` is stored outside the data
directory, preserve that exact value with the backup.

With Go 1.26.6 or newer:

```sh
go install github.com/RandomCodeSpace/kb@v2.0.0
kb version
```

The release provides CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Download the matching binary and `SHA256SUMS`,
then verify it before installation. For Linux amd64:

```sh
grep ' kb-linux-amd64$' SHA256SUMS | sha256sum -c -
```

Each binary records the module version, source revision, target platform, Go
1.26.6 toolchain, and an unmodified source tree in its embedded metadata.
