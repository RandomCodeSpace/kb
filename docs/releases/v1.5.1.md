# kb v1.5.1

v1.5.1 is a patch release refining the board card layout introduced in v1.5.0.
Cards now use only the rows their content needs while retaining the frame-based
height ladder as a ceiling. This puts more useful cards on screen without
clipping whole cards at the bottom of a column or miscounting the overflow cue.

The card interior now separates prose, metadata, and labels with spacing only
when both neighboring sections are present. Compact cards remain two rows. Card
descriptions also preserve source line breaks instead of joining separate lines
before markdown layout.

This release does not change the CLI, HTTP API, MCP tool surface, database
schema, or dependencies. It contains the changes merged in
[#242](https://github.com/RandomCodeSpace/kb/pull/242) and
[#244](https://github.com/RandomCodeSpace/kb/pull/244).

## Upgrade

Install the release with the Go toolchain:

```sh
go install github.com/RandomCodeSpace/kb@v1.5.1
```

Existing boards require no migration beyond the schema already introduced by
v1.5.0.
