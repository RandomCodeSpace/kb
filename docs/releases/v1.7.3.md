# kb v1.7.3

v1.7.3 makes the TUI calmer and easier to scan, and gives Markdown descriptions
room to work without leaving the terminal.

## TUI

- The board and overlays use a neutral charcoal hierarchy with a restrained
  focus accent. Labels keep stable hashed colors in a muted blue, teal, plum,
  ochre, and sage wheel.
- Labels wrap across complete rows on cards and in details instead of dropping
  content at the old row limit. Narrow and compact boards can scroll to every
  label.
- Card details are grouped into overview, description, related items, and
  comments. Comment timestamps use a consistent UTC format, and the top bar no
  longer repeats the default user name.
- Description and comment text in the read-only detail view can be selected by
  dragging. `Ctrl+A` selects all readable text and `y` sends an OSC 52 copy
  request. Clipboard delivery depends on the terminal and any remote session or
  multiplexer in between.
- `V` opens a plain snapshot of the read-only detail text for native terminal
  selection. Mouse reporting stays off in that view until `Esc` returns to the
  detail pane.

## Markdown editing

- The description editor now soft-wraps through the Bubbles textarea while
  keeping the stored Markdown source unchanged.
- `F2` opens a rendered Markdown preview. `Esc` returns to the unsaved source
  with its cursor and scroll position intact.
- `F3` opens a plain snapshot of the unsaved description for native terminal
  selection. `Esc` returns to the same unsaved source and editor state.
- New-comment composition soft-wraps at the pane width. Preview and terminal
  snapshot modes remain specific to the full description editor.

## Upgrade

Make a cold backup of the data directory first. Then, with Go 1.26.5 or newer:

```sh
GOTOOLCHAIN=local go install github.com/RandomCodeSpace/kb@v1.7.3
kb version
```

The release provides CGO-free binaries for Linux amd64 and arm64, macOS amd64
and arm64, and Windows amd64. Each binary records Go 1.26.5 in its embedded
build metadata.
