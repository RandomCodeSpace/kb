# kb v1.2.0

v1.2.0 removes the per-user namespace surface from the local commands. kb is a
local-first tool; the board you see is the board you have.

## Breaking change

- The `--user` flag and the `KB_USER` environment variable are removed from the
  CLI, the TUI, and `kb mcp`. All local commands operate on the single default
  namespace. Passing `--user` now fails with an unknown-flag error, and
  `KB_USER` is ignored.
- The database schema is unchanged and no data is deleted. If the database
  contains tasks created under another namespace in an earlier version, local
  commands print a one-line warning naming those namespaces; that data remains
  in the file and is still reachable through `kb serve` or an earlier kb
  release.
- `kb serve` is unaffected: its HTTP API and storage keys are unchanged.

## Upgrade from v1.1.0

No database migration is required. Existing tasks, comments, links, tombstones,
settings, encrypted credentials, and import provenance remain in the same data
directory. Keep `kb.db`, `kb.db-wal`, `kb.db-shm`, and `secret` together when
backing up or moving a board.

If you never set `KB_USER` or passed `--user`, nothing changes.

## Install and verify

With Go 1.25.8 or newer:

```sh
go install github.com/RandomCodeSpace/kb@v1.2.0
kb version
```

The release contains five CGO-free binaries:

- Linux amd64 and arm64
- macOS amd64 and arm64
- Windows amd64

Download the matching binary and `SHA256SUMS` from the release, then verify it
before installation:

```sh
grep ' kb-linux-amd64$' SHA256SUMS | sha256sum -c -
```

Substitute the downloaded asset name. On macOS, pipe the matching manifest
line to `shasum -a 256 -c -`. On Windows, compare
`Get-FileHash -Algorithm SHA256` with the matching manifest line.

Every attached binary is built from the annotated v1.2.0 tag with `-trimpath`
and stripped debug data. Embedded Go metadata records the module, version,
source revision, target OS and architecture, and an unmodified source tree.
